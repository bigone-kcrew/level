# 03. 타기관 비교

[← 목록](../README.md) · [진단](diagnosis.md) · [개정안](amendments.md)

공공기관 40여 곳의 근무평정 관련 내규·단체협약을 경영공시 기반으로 대조했습니다.
중소벤처기업부 산하 기관은 **굵게** 표시했습니다.

---

## 상위 지침 — 등급 분포 요건

「공기업·준정부기관 예산운용지침」(예산집행지침)의 등급 분포 요건입니다.
감사원 감사보고서와 주무부처 종합감사 지적사항, 다수 기관 내규에서 인용된 내용입니다.

| 요건 | 내용 |
|---|---|
| 차등 등급 수 | 5개 등급 이상 |
| 등급별 인원(부서) 비율 | 최고 등급 10% 이상 / 최저 등급 및 차하위 등급 **합하여** 10% 이상 / 특정 등급 50% 초과 금지 |
| 차등 수준 | 최고등급 성과급 지급액 ≥ 차하위등급 지급액 × 2 |
| 준용 | 내부평가급의 지급 횟수·차등 등급 수·등급별 인원 비율·차등 수준은 경영평가 성과급 규정 준용 |

**적용 범위: 성과급.** 승진용 근무평정의 등급 분포를 규율하는 규정이 아닙니다.

### 지침 위반으로 지적된 사례

| 기관 | 지적 내용 |
|---|---|
| **한국벤처투자** (2022년 중기부 종합감사) | 성과급 최고등급 3%(10% 미달), 최고:차하위 차등 1.58배(2배 미달), 3개년 성과급 등급이 없음에도 지급 |
| 강원랜드 (2022년 감사원 정기감사) | 차등 등급 수 3~4개만 운영(5개 미달), B등급에 51% 배정(50% 초과), 최저 등급에 4~6%만 배정 |
| 국가생명윤리정책원 (2020년 복지부 종합감사) | 부서·직급별 평가단위 구분 없이 전체 직원에 일괄 등급 부여 → 2급 이상 75%가 S등급, 3급 이하는 21% |
| 한국인터넷진흥원 (2022년 과기부 종합감사) | 최고:차하위 2배 차등 요건 미인지, 경영평가 인센티브 차등 부적정 |

국가생명윤리정책원 사례는 **평가단위를 부서·직급별로 나누지 않으면 상위 직급에 유리해진다**는
점을 감사에서 확인한 것입니다. 창업진흥원은 직급별로 배정하므로 이 문제는 없습니다.

### 성과급 등급·지급률의 규정화 수준

| 기관 | 규정화 수준 |
|---|---|
| 한국상하수도협회 | 보수규정세칙 제14조 **본문 표**에 등급·지급률·인원비율 전부 명시 (S 134 / A 115 / B 100 / C 85 / D 66 / E 0%, 10/15/50/15/10) |
| 한국소비자원 | 성과급 지급지침 제6조에 최고 10% 이상·특정등급 50% 이하·2배 차등 명시 |
| 한국산업인력공단 | 보수규정시행규칙 제17조③ + 별표 4 |
| 주식회사 에스알 | 노사협의회에서 등급 체계·지급률 개정 협의 (E등급 신설 시 부여 사유를 성과관리위원회 심의로 한정) |
| **창업진흥원** | **보수규정 제25조③에서 "원장이 따로 정한다"로 위임. 규정집에 표 없음.** 성과관리 편람에만 "예시"로 존재 |

## 등급 분포 (근무평정)

| 기관 | 등급 체계 | 특징 |
|---|---|---|
| **창업진흥원** | S 20 / A 30 / B 40 / **C 10** | **C등급 10% 강제.** 비율이 규칙 본문에 없고 원장 위임(제26조③) |
| 해양환경공단 | S 10 / A 20 / B 40 / C 20 / D 10 | **인사규정 시행규칙 제33조 본문에 명시** + 인원별 배분표(별표 7) |
| 한국공예디자인문화진흥원 | 10 / 20 / 40 / 20 / 10 | 지침 제11조 본문 명시, 배분 인원 불일치 시 일부 조정 가능 |
| 차세대수치예보모델개발사업단 | 10 / 20 / 40 / 20 / 10 | 사업단장이 1차 평가자인 경우 절대평가 가능 |
| 한국직업능력연구원 | S 10 / A 15~20 / B 40~50 / C 15~20 / D 10 | **범위로 규정** + 기관 운영상 필요시 조정 |
| 건축공간연구원 | S·A·B·C 상대평가, **D는 절대평가** | **기준 미달자에게만 D 부여.** 예산·재정 감안 10% 범위 조정 |
| 한국법제연구원 | 별표 비율 | 원장이 10% 범위 조정 + **사회적 배려 직원 D→C 조정** |
| 한국나노기술원 | S 5 / A 15 / B 60 / C 15 / D 5 | **S·D 해당자 없으면 각각 A·C에 가산** |
| 한국청소년상담복지개발원 | 최고·최저 각 10% 이상, 특정등급 50% 이하 | 그룹 5명 미만이면 4등급 이하로 차등 |
| 육아정책연구소 | **A / B / C 3등급, B가 90% 이상** | 차등 최소화 방향 |
| 코레일관광개발 | 3급 이상 10/20/40/20/10<br>**4급 이하 10/20/55~70/0~10/0~5** | **하위 직급은 최하위 등급을 0%까지 허용** |
| 대한법률구조공단 | 상위 30% / 30~70% / 70~90% / 90%~ | 4명 미만이면 한 등급에 1명 초과 금지, 4등급 해당자 없으면 3등급에 가산 |
| 한국조폐공사 | 별표 분포도 | 상위등급 해당자 없으면 하위등급 인원 초과 허용, E 없으면 D에 합산 |
| 제주국제자유도시개발센터 | S 10 / A 20 / B 40 / C 20 / D 10 | 위원회 의결로 등급 상·하향 조정 가능 |

**최하위 등급을 강제하지 않는 방식이 여러 형태로 존재합니다** — 절대평가 기준 미달자에게만 부여(건축공간연구원),
해당자 없으면 인접 등급에 가산(한국나노기술원·한국조폐공사·대한법률구조공단),
하위 직급은 0%까지 허용(코레일관광개발), 사회적 배려 직원 상향 조정(한국법제연구원).

## 평정자 편차 보정

| 기관 | 방식 |
|---|---|
| **창업진흥원** | **사전** 제한 — 피평가자 그룹 평균 80점 이내 강제. 규칙 제9조④에 "평균 등을 적용하여 보정할 수 있다"는 근거만 있고 산식 비공개 |
| 정보통신기획평가원 | **사후** — 업무성과평가요령 제39조②: "평가자별 평가점수 편차보정을 위해 보정절차를 실시한다. 보정기준은 **평균·표준편차일치법**을 적용하며, 평균점수는 80점으로 한다" |
| 한국지역난방공사 | **사후** — 근무성적평정세칙 제10조③: "인사담당부서는 …**평정자의 평정 성향에 따른 결과 편향성 조정**을 위한 점수 조정을 실시할 수 있다" |
| **중소기업기술정보진흥원** | **사후** — 근무평정지침: "개인평정 결과의 타당성과 신뢰도를 제고하기 위해 **통계기법을 활용하여 보정**할 수 있다" |
| 한국부동산원 | **사후** — 보수규정 시행요강 제11조⑤: "그룹별로 **평균과 표준편차가 동일하도록 보정**하여 반영한다" |
| 한국나노기술원 | **사후** — 근무평정지침 제9조⑥-1: "평정자의 성향에 따른 점수 보정을 실시" |

**평균·표준편차를 사후에 일치시키는 방식이 이미 여러 기관에서 규정화되어 있습니다.**
창업진흥원 규칙 제9조④에도 근거가 있으나 사전 평균 강제와 병행되어 실효가 없습니다.

| 기관 | 규정 |
|---|---|
| 한국생명존중희망재단 | 근무평정지침 제4조②: "평정의 책임성 제고를 목적으로 평정자가 …**최상위등급 또는 최하위등급을 부여하였을 경우, 반드시 사유를 기재**하여야 한다" |

| 대한법률구조공단 | 직원근무평정규정 제8조③: 감점 사유·기준을 **평정대상기간 이전에 미리 설정하고 대상자에게 공개** |
| 코레일관광개발 | 근무평정 세칙 제4조⑦: 평정 시 **직상위 직위자의 의견 반영 의무** |
| **창업진흥원** | 규칙 제4조①3호 "**가능한 범위 내에서** 평가점수가 동일하지 아니하도록" — 사실상 무력 |

## 평가결과 공개 범위

| 기관 | 공개 수준 |
|---|---|
| 부산항만공사 (단체협약 제29조③) | **등급, 승진서열, 평정항목별 평가점수, 평정기술서**를 전산시스템에서 본인 열람. 조합이 이의를 제출하면 공사가 **3일 내 통보** |

| 기관 | 조항 |
|---|---|
| **창업진흥원** (제27조①) | "인사평가 제도 및 평가 문항의 설계·변경 시 **사전에 조합의 동의를 받아야 한다**" |

| 부산항만공사 (제29조) | "공사의 근무평가 방법, 기준 등 구체적인 시행방안에 대해 **노사간 성실히 협의**하여 시행한다" + 결과 열람·조합 의견 제출권 |

| 충남대학교병원 (제23조④) | 인사평정 원칙은 **인사제도개선위원회**에서 개선 |
