# 03. 타기관 비교

## §0 조사 방법

| | |
|---|---|
| 대상 | ALIO 경영공시 기관 내규 — **355개 기관 · 규정 파일 36,190건** |
| 방법 | 전 파일을 **조(條) 단위로 분할** → 근무평정 문맥 조문만 선별 → 문장 단위 판정 → 표본 감사로 오탐 제거 |
| 제외 | 채용·수습·자문변호사·연구과제 등 근무평정과 무관한 문맥 |
| 기준일 | **2026-09-10** |

**검색 표본이 아니라 전수다.** 용어가 기관마다 달라 키워드 검색으로는 누락이 발생하므로, 조문
전체를 훑어 「무엇을 하는 조항인지」로 분류했다.

전수 집계의 상세 결과와 기관 명단은 [부록 — 사전·사후 조정 전수 집계](census.html)에 있다.

### 1-5 조정 여유 — 합계 0 방식

| 기관 | 조문 |

| **새만금개발공사** | 인사규정 시행세칙 제13조② — "직무등급별로 **평균표준편차 일치법**을 적용하여 환산점수로 산출" |
| | 같은 조 ③ — "조정자는 제2항의 근무평가 점수를 **±10점 범위 내로 조정할 수 있다. 다만, 평가 단위인 비교집단 내의 조정점수의 합계는 0이 되도록 한다**" |

## §2 이동자 평정 — 창진원과 다수 기관의 차이

### 2-1 점수를 누가 부여하는가

**다수 기관은 「현 부서에서 평가하고 전 부서장의 의견만 듣는」 방식이다.** 전 부서장이 점수를
직접 매기지 않으므로 "나갈 사람" 낙인이 원리적으로 발생하지 않는다.

| 기관 | 조문 |
|---|---|
| **과학기술정책연구원** | 제18조 — "**현 근무부서장이 전 근무부서장의 의견을 들어** 평가한다" |
| **과학기술사업화진흥원** | 제7조 — "이전 부서장의 의견을 청취하여 **평가시점 기준 현재 부서에서** 평가" |
| **의료기관평가인증원** | 제8조 — "평가일 기준 **현재 부서에서** 실시한다. 단, 변경 전 부서장 의견을 청취한다" |
| **해양수산과학기술진흥원** | 제16조 — "개인성과평가는 **마지막 소속부서장이** 전 소속부서장 의견을 청취하여 평가" |
| **한국교육학술정보원** | 제9조①② — "**현부서의 계통에 따라** 평가하고 필요시 전 부서 평가자 의견 참조" · "평가자가 이동한 경우 **전임자에게 가평가를 의뢰**" |
| **창업진흥원** | 제6조① — **전·현 부서 근무기간 가중 합산** (전 부서장이 직접 점수 부여) |

### 2-2 최소 근무기간 기준

| 기관 | 기준 |
|---|---|
| **장애인기업종합지원센터** *(중기부)* | 제18조② — "근무월수 **1개월 미만** 부서의 업무는 평가에 반영하지 아니한다" |
| **한국양성평등교육진흥원** | 제6조 — "**2개월 이상** 근무한 실적에 대해 근무기간에 비례하여 평가" |

| 한국보건의료정보원 · 중앙사회서비스원 | 같은 취지 |

| **건설근로자공제회** | 제85조③ — "평정기준일 전 **3개월 내**에 소속이 변경된 경우 종전 부서에서 평정" |

새 부서장에게 평가받는 일이 이 기준 때문에 발생한다.

| **무역안보관리원** | 제8조③ — "전 근무부서의 **폐쇄 등 불가피한 사유**가 있는 경우 현 근무부서에서 평정" |
| **창업진흥원** | 제8조② — "평가하기 곤란한 경우에는 원장이 별도로 평가자를 지정한다" |
| | 별표1 주1 — "부서장 **직무대리 포함**" *(직무대리를 평가자로 인정)* |

**창진원은 지정 근거만 있고 승계 순서·시점·통지가 없다.** 그리고 직무대리를 평가자로 명시적으로
인정하는데, 이는 한국출판문화산업진흥원의 규정과 정면으로 반대다.

## §7 노동조합 전임자·근로시간면제자 평정

전임자·근로시간면제자 평정을 규정한 기관은 **55곳**이며, 확인된 방식은 네 갈래다.
**「최근 N회 평균」 방식은 355개 기관 중 창업진흥원 외 한 곳도 확인되지 않았다.**

상세는 [〈06 전임자 평정〉 별책](union.html) §3에 있다.

| 방식 | 기관 |
|---|---|
| **직전 점수와 동일 직급 평균 중 유리한 값** | 한국산업안전보건공단 제16조③ · 한국소비자원 |
| 동일 직급 평균 부여 | 한국전력거래소 · 오송첨단의료산업진흥재단 · 한국방송광고진흥공사 |
| 중간등급(B) 고정 | 대한석탄공사 · 통일연구원 · 서울올림픽기념국민체육진흥공단 · 한국청소년활동진흥원 |

## §8 상위 지침 — 무엇을 규율하고 무엇을 규율하지 않는가

「공기업·준정부기관 예산운용지침」의 차등 요건은 **성과급 지급등급**에 적용된다.

| 지침 요건 | 내용 |
|---|---|
| 등급 수 | 차등 **6개 등급 이상** (미지급 최하위 포함) |
| 최고등급 | 10% 이상 |
| 최저 + 차하위 | 합계 10% 이상 |
| 특정등급 | 50% 초과 금지 |
| 최고등급 지급률 | 차하위의 **2배 이상** |

**이 요건은 승진용 근무평정 등급(S·A·B·C 4단계)을 규율하지 않는다.** 창진원도 내부성과평가에서
S~E 6등급 체계를 별도로 운영하고 있다. 따라서 근무평정 등급 비율을 규칙에 명시하는 것(개정 10)은
상위 지침과 충돌하지 않는다.

## §9 창업진흥원의 위치 — 요약
