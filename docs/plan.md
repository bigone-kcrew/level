# 05. 근무평정제도 개편 추진계획

작성 기준일 2026년 9월 10일 · 창업진흥원노동조합

---

## 1. 배경

사용자 측은 2026년 1분기 노사협의회에서 근무평정제도 개선을 제안하고, 노동조합의 3개 제안
(정량평가 전환 / 평정자·피평정자 일치 / 대소부서 편차 보정)에 대해 개편(안)을 제시했습니다.
다만 개편(안)에는 구체적 설계가 없습니다.

노동조합이 개편을 요구하는 이유는 **근무평정 결과에 대한 불신**입니다. 발생 경로는 다음과 같습니다.

```
목표설정이 사후(익년 2월)  →  목표가 평가기준이 되지 못함
        ↓
사실상 전면 정성평가
        ↓
+ 사전조정계수(그룹 평균 80점 강제 = 제로섬)
        ├── 제도 숙지 평정자 → 전략적 극단화(표적화가 제도적으로 가능)
        └── 이해 부족 평정자 → 균등 배분(판별력 소실)
        ↓
점수의 분산이 '직원 간 차이'가 아니라 '평정자 간 차이'에서 발생
        ↓
+ 승진명부가 최근 2회만 반영  →  특정 부서장의 1~2년이 승진을 결정
        ↓
"라인을 타야 승진한다"
        ↓
+ 평정점·순위 비공개 + 이의신청 심의는 인사위원회 단독  →  검증·구제 불가
```

→ 상세: [01. 제도 진단](diagnosis.html)

## 2. 목표

**차등을 없애는 것이 목표가 아닙니다. 차등이 실제 성과 차이에서 나오게 만드는 것이 목표입니다.**

| 구분 | 목표 상태 | 검증 지표 |
|---|---|---|
| 평정자 편차 제거 | 어느 평정자 아래에 있든 상위·하위 등급 획득 기회가 같다 | 평정자 유형별 S등급 획득률 편차가 설정 비율(20%) ±3%p 이내 |
| 승진 예측가능성 | 특정 평정자 1인의 영향이 희석된다 | 승진명부 반영을 최근 3년 균등으로 확대 |
| 목표관리 정상화 | 목표가 평가 이전에 확정된다 | 목표설정·합의 완료가 평가대상기간 개시 후 1개월 이내 |
| 검증가능성 | 결과에 이의를 제기할 근거가 제공된다 | 평정점·직급 내 순위 본인 공개, 평정자 설명 의무 |
| 규범 안정성 | 핵심 기준이 원장 재량이 아니라 규정에 있다 | 등급별 비율·보정 산식·성과급 지급률의 규정 본문 명시 |

## 3. 개편 방향 (설계 원칙)

1. **사전에 평균을 강제하지 않고, 사후에 평정자 편차를 표준화한다.**
   부서 내 순위는 보존하므로 부서장의 평가 권한은 그대로 유지된다.
2. **보정 산식과 모수를 규칙 별표에 명시하고 평가 실시 전에 공개한다.**
   통계 보정이 블랙박스가 되면 새로운 불신이 생긴다.
3. **표준화가 고치지 못하는 것(악의적 표적화)은 사유 기재·반영 회차 확대·재심기구로 보완한다.**
4. **정량평가와 조직 성과는 성과급 트랙(내부평가·경영평가)에서 다루고, 근무평정은 승진용으로 순화한다.**
5. **등급별 비율을 규칙 본문에 명시한다.** 원장 재량 위임은 노사 합의 절차를 우회한다.

### 근거가 이미 마련되어 있는 부분

| 항목 | 기존 근거 |
|---|---|
| 사후 보정 | 근무평정규칙 **제9조④** "결과의 신뢰도를 제고하기 위해 평균 등을 적용하여 보정할 수 있으며" |
| 사전조정계수 폐지 | 규칙에 근거 없음 — **연도별 계획(안)에만 존재**하므로 규칙 개정 없이 계획 변경으로 가능 |
| 개편 절차 | 단체협약 **제27조①** 인사평가 제도·평가문항 설계·변경 시 사전 조합 **동의** |
| 의결 효력 | 근로자참여법 **제24조·제30조2호** 의결 사항 미이행 시 1천만원 이하 벌금 |
| 제도화 필요성 | **2025년도 경영평가 보고서** — "등급이 규정화되지 않았다", "심의위원회를 마련해 등급을 최종확정하는 구조 필요", "평가 결과 조정 시 위원회 활용" |

경영평가단 권고와 노동조합 요구가 일치합니다. **"노조 요구"가 아니라 "경영평가 지적사항 이행"으로
논의를 구성하는 것이 유효합니다.**

## 4. 시행 시점 구분 — 무엇을 언제부터 적용할 수 있는가

2026년 평가대상기간은 이미 진행 중입니다. 소급 적용이 가능한 것과 불가능한 것을 나눠야 합니다.

### 4-1. 2026년 평정(2027년 2월 실시)부터 적용 가능

평정 **실시 방법**에 해당하므로 평가대상기간 종료 후 개정해도 적용에 무리가 없습니다.

- 사전조정계수 폐지 + 사후 평균·표준편차일치법 (제9조의2, 별표 9)
- 최고·최저 등급 부여 시 사유 기재, 획일 부여 시 근거 명시 (제4조)
- C등급을 절대평가 기준 미달자에게만 부여 (제26조③)
- 평정점·직급 내 순위 본인 공개, 평정자 설명 의무, 근무평정심의위원회 (제28조, 제28조의2)
- 다면평가 전원 동일점수 부여 시 산정 제외, 유효응답 요건, 3명 이하 부서 통합 (제22조)
- 공통평가(정보보안) 폐지 (제23조·별표 6)

### 4-2. 2027년 평가대상기간부터 적용

목표설정을 전제로 하므로 **연도 개시 전에 개정이 끝나야** 합니다.

- 목표설정·합의를 평가대상기간 개시 후 1개월 이내로 (제15조②)
- 7월 중간점검 면담 의무화, 목표 수정 사유 명문화 (제15조④⑤)
- 업적평가 「업무 요청사항 이행정도」 → 「합의된 성과목표 달성도」 대체 (별표 3)
- 반영비율 변경: 업적 60 / 역량 20 / 다면·상향 20 (제9조②)

> **실질 마감은 2026년 12월입니다.** 2027년 1월에 연초 목표설정을 최초 시행하려면
> 그전에 규칙 개정이 의결되어야 합니다. 근무평정규칙의 최근 개정이
> 2024.11.28. / 2025.12.22. / 2026.1.27.에 이루어진 것도 같은 주기입니다.

### 4-3. 경과조치가 필요한 사항

- **승진후보자 서열명부 3년 균등 반영** — 3년치 평정점이 확보되지 않은 대상자 처리
- **사용자 측 개편(안)의 확정 시기 변경**(차년도 8월) — 현행 실무는 2월 산출 → 3월 명부 → 4~5월 승진.
  전환기에 승진 심사에 쓸 평정점이 없는 공백이 발생하므로 노사협의회 의결로 확정 필요

## 5. 단계별 추진계획

### 1단계 — 자료 확보와 안건 성격 규정 (2026년 9~10월)

| 과제 | 검증 기준 |
|---|---|
| 자료 요구 7건 발송 | 접수 확인 및 회신 기한 명시 |
| 평가자별 분포를 **부서 규모 구간별 집계** 형태로 재요구 | 개인정보 예외(근참법 제14조 단서)에 해당하지 않음을 명시 |
| 4분기 정기 노사협의회 안건 상정 | 의제 통보(근참법 제13조③ 회의 7일 전) 확인 |
| 안건을 **단체협약 제27조① 동의 사항**으로 성격 규정 | 회의록에 기재, 상호 서명(단협 제89조②③) |

자료 요구 목록 (→ [04. 요구사항](bargaining.html#6-자료-요구))

1. 최근 3년 평가자별 부여점수 분포 통계 (부서 규모 구간별 평균·표준편차, 개인 식별 불가 형태)
2. 최근 3년 직급별·부서별 등급 분포
3. 최근 3년 C등급 2회 이상 반복 부여 인원 수
4. 최근 3년 이의신청 접수·인정 건수
5. 승진후보자 서열명부 산식 (원장이 따로 정한 문서)
6. 내부평가 세부 기준 (미래인재실 성과평가 계획)
7. 사용자 측 개편(안)의 부서평가 반영 비율·방식·직급별 차등 여부

### 2단계 — 협의 기구 구성과 개정안 협의 (2026년 10~11월)

| 과제 | 검증 기준 |
|---|---|
| **노사 동수 평가제도개선위원회** 설치 제안 | 단협 제109조 보충협약 또는 노사협의회 의결 |
| 개정안 조문별 협의 | 신구대조표 기준 조문별 합의·이견 정리 |
| 자료 확보 시 시뮬레이션 재검증 | 실측 분포로 모수(목표 표준편차) 재산정 |

선례: 한국영상자료원 단체협약 제46조② — "상향평가제도 도입 및 반영, **절대평가제도 전환** 등은
조합위원장을 포함한 **노사 동수 평가제도개선위원회**를 통해 개선한다"

### 3단계 — 규칙 개정 의결 (2026년 12월)

| 과제 | 검증 기준 |
|---|---|
| 근무평정규칙 개정 의결 | 노사협의회 출석위원 3분의 2 이상 찬성(근참법 제15조) |
| 인사규정 제23조(승진명부) 개정 | 3년 균등 반영 + 산정 결과 본인 공개 |
| 보수규정 성과급 등급·지급률 명시 | 변경 시 노사협의회 의결 조항 포함 |
| 경과조치 확정 | 승진 공백 방지 조항 명문화 |

### 4단계 — 시행과 사후 검증 (2027년)

| 시점 | 과제 | 검증 기준 |
|---|---|---|
| 2027.1 | 연초 목표설정 최초 시행 | 1월 중 목표 합의 완료율 100% |
| 2027.2 | 2026년 평정에 사후 표준화 최초 적용 | 평정자별 보정 전·후 분포 통계 노사협의회 보고 |
| 2027.2~3 | 평정점·순위 공개, 심의위원회 운영 | 이의신청 처리 결과 서면 통지 |
| 2027.7 | 중간점검 면담 최초 시행 | 면담 기록 작성률 |
| 2027.12 | 1년차 운영 평가 | 평정자 유형별 등급 획득률 편차 ±3%p 이내 달성 여부 |

## 7. 사용자 측 개편(안)에 대한 입장

| 사측 제안 | 입장 |
|---|---|
| 연초 목표설정을 통한 목표관리 실현 | **동의** — 중간점검 의무화·목표수정 절차·합의 불성립 시 조정 절차 추가 필요 |
| 다면·상향 평정자를 과거 동일부서까지 확대 | **조건부 동의** — 무작위 선별 기준 명문화, 유효응답 요건, "모르면 미평가" 조항 필요 |
| 부서 규모별 평균 허용범위 차등화(5명 이하 75~85) | **방식 이견** — 하한 75는 소부서 평정자 재량을 넓힘. 축소추정 사후 표준화가 같은 목적을 연속적으로 달성 |
| 경영평가 부서평가를 근무평정에 반영 | **성과급 트랙은 동의, 승진용 반영은 조건 필요** — 최소한 직급별 차등(노사발전재단식) |
| 내부평가 성과급 폐지 | **반대** — 공공기관에서 폐지한 성과급 항목은 재신설 곤란. 근무평정 비중이 42%→60%로 상승 |
| 근무평정 확정을 차년도 8월로 변경 | **경과조치 전제 동의** — 전환기 승진 공백 방지 조항 필요 |

**교섭 구조상 유의점**: 사측 개편(안)은 근무평정 확정 시기 변경 없이는 성립하지 않고,
시기 변경은 승진 시기 변경을 수반하므로 단체협약 제28조②(정기승진 6월·12월)와 연동됩니다.
따라서 **시기 조정에 대한 조합 동의가 개편안 성립의 전제**입니다.
